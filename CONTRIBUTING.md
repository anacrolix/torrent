# Contributing

## Pull requests

Please open pull requests with **Allow edits from maintainers** enabled. This lets maintainers update your branch from master, resolve conflicts and push small fixes without a round trip. You can tick it when opening the pull request, or later from the checkbox on the pull request page. See [Allowing changes to a pull request branch created from a fork](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/allowing-changes-to-a-pull-request-branch-created-from-a-fork).

GitHub only offers this option for forks owned by a personal account. If your fork belongs to an organization, consider pushing the branch to a personal fork instead, or say so in the pull request.

A bot comment will remind you if the option is off on a pull request from a fork.
